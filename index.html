Purpose of this questionnaire

This questionnaire will help document where employee information is kept, who is responsible for it, how it is updated, and which record should be followed when information is different.

Please answer using the information you have. Every question is optional. If you do not know an answer, choose Not sure — that is a perfectly good answer. More questions appear only when they are needed.

Please note: This is an information-gathering exercise. It does not ask you to change any spreadsheet, system, or employee record. Do not include passwords, national ID numbers, medical details, or other sensitive personal information in your answers.
About links: Where a question asks for a file, you can paste a link (for example from Google Drive, OneDrive, or SharePoint) so that I can find it. If you do not have a link, just write the file name.

Which record to follow when information is different

For example, a person's department is different in two files.

4.1 Do two records ever show different information for the same person?

Please do not include real names or private details in the example.

4.2 Is there one main file or system that everyone should trust as the correct one?

Add a link if you have one. No link? Just write the name.

4.3 Does the correct record depend on the type of information?

For example, Human Resources may confirm whether someone is still employed, while a department confirms a clinic schedule.

4.4 When two records disagree, who decides which one is correct?
4.5 Is there a written rule or procedure for this?

Add a link if you have one. No link? Just write the name.

Changes, transfers, leave, and departures

6.4 Are the previous details kept so that changes can be reviewed later?
6.5 When someone's information changes, are all the relevant records updated?
